# ES6 Promises

This project contains JavaScript functions demonstrating ES6 Promises, including promise creation, handling, error handling, and promise utilities.

## Files

- `0-promise.js` - Returns a Promise
- `1-promise.js` - Returns a promise that resolves or rejects based on a boolean
- `2-then.js` - Handles promise resolution and rejection
- `3-all.js` - Uses Promise.all to handle multiple promises
- `4-user-promise.js` - Returns a resolved promise with user data
- `5-photo-reject.js` - Returns a rejected promise
- `6-final-user.js` - Uses Promise.allSettled to handle multiple promises
- `7-load_balancer.js` - Returns the first resolved promise
- `8-try.js` - Throws an error for division by zero
- `9-try.js` - Wraps a function in a try-catch guardrail

## Setup

```bash
npm install
```

## Usage

```bash
npm run dev <file>.js
npm run test
npm run full-test
```
