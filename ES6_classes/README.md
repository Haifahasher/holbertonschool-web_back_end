# ES6 Classes

This project covers ES6 classes, methods, inheritance, and metaprogramming concepts.

## Learning Objectives

- How to define a Class
- How to add methods to a class
- Why and how to add a static method to a class
- How to extend a class from another
- Metaprogramming and symbols

## Requirements

- All files interpreted/compiled on Ubuntu 20.04 LTS using node 20.x.x and npm 9.x.x
- Code should use the `.js` extension
- Code will be tested using Jest Testing Framework
- Code will be analyzed using ESLint
- All classes must be exported

## Setup

1. Install NodeJS 20.x.x
2. Install project dependencies:
   ```bash
   npm install
   ```

## Files

- `0-classroom.js` - Basic ClassRoom class
- `1-make_classrooms.js` - Function to initialize classrooms
- `2-hbtn_course.js` - HolbertonCourse class with getters and setters
- `3-currency.js` - Currency class with methods
- `4-pricing.js` - Pricing class with static methods
- `5-building.js` - Abstract Building class
- `6-sky_high.js` - SkyHighBuilding class extending Building
- `7-airport.js` - Airport class with custom toStringTag
- `8-hbtn_class.js` - HolbertonClass with valueOf and toString
- `9-hoisting.js` - Fixed hoisting issues with classes
- `10-car.js` - Car class with cloneCar method using Symbols
