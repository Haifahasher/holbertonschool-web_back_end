# ES6 Basics

This project covers ES6 (ECMAScript 2015) fundamentals and new features.

## Learning Objectives

- Understanding what ES6 is
- Learning new features introduced in ES6
- Understanding the difference between constants and variables
- Working with block-scoped variables
- Using arrow functions and default function parameters
- Understanding rest and spread function parameters
- Using string templating in ES6
- Working with object creation and properties in ES6
- Understanding iterators and for-of loops

## Requirements

- All files interpreted/compiled on Ubuntu 20.04 LTS using node 20.x.x and npm 9.x.x
- Code should use the `.js` extension
- Code will be tested using Jest Testing Framework
- Code will be analyzed using ESLint
- All functions must be exported

## Setup

1. Install NodeJS 20.x.x
2. Install project dependencies:
   ```bash
   npm install
   ```

## Files

- `0-constants.js` - Demonstrates `const` and `let` usage
- `1-block-scoped.js` - Demonstrates block-scoped variables
- `2-arrow.js` - Demonstrates arrow functions
- `3-default-parameter.js` - Demonstrates default function parameters
- `4-rest-parameter.js` - Demonstrates rest parameter syntax
- `5-spread-operator.js` - Demonstrates spread operator
- `6-string-interpolation.js` - Demonstrates template literals
- `7-getBudgetObject.js` - Demonstrates object property shorthand
- `8-getBudgetCurrentYear.js` - Demonstrates computed property names
- `9-getFullBudget.js` - Demonstrates ES6 method properties
- `10-loops.js` - Demonstrates for-of loops
- `11-createEmployeesObject.js` - Creates an employee object
- `12-createReportObject.js` - Creates a report object
