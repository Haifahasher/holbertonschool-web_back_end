# NodeJS Basics

This project contains basic Node.js exercises covering:
- Running JavaScript with Node.js
- Using Node.js modules
- Reading files synchronously and asynchronously
- Creating HTTP servers with Node.js http module
- Creating HTTP servers with Express.js
- Organizing a complex server structure

## Files

- `0-console.js` - Basic console output function
- `1-stdin.js` - Reading from stdin
- `2-read_file.js` - Synchronous file reading
- `3-read_file_async.js` - Asynchronous file reading
- `4-http.js` - Simple HTTP server
- `5-http.js` - HTTP server with routes
- `6-http_express.js` - Simple Express server
- `7-http_express.js` - Express server with routes
- `full_server/` - Full server structure with controllers and routes

## Installation

```bash
npm install
```

## Running

```bash
# Run individual files
node 0-main.js

# Run the full server
npm run dev
```
