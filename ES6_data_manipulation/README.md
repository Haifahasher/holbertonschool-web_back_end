# ES6 Data Manipulation

This project contains JavaScript functions for data manipulation using ES6 features like map, filter, reduce, Sets, Maps, and TypedArrays.

## Files

- `0-get_list_students.js` - Returns an array of student objects
- `1-get_list_student_ids.js` - Returns an array of student IDs
- `2-get_students_by_loc.js` - Filters students by location
- `3-get_ids_sum.js` - Returns the sum of all student IDs
- `4-update_grade_by_city.js` - Updates student grades by city
- `5-typed_arrays.js` - Creates a TypedArray with Int8 values
- `6-set.js` - Creates a Set from an array
- `7-has_array_values.js` - Checks if array values exist in a Set
- `8-clean_set.js` - Cleans a Set and returns a formatted string
- `9-groceries_list.js` - Returns a Map of groceries
- `10-update_uniq_items.js` - Updates unique items in a Map

## Setup
